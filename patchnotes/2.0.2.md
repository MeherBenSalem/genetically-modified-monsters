# Spore & Stem 2.0.2

## New

- **Minecraft 26.2 and 26.3.** Spore & Stem now runs on Minecraft 26.2 and 26.3, on both Fabric and NeoForge. Every
  block, item, food and creature comes along, with the Mycosis infection and the Myceliarch boss.
- On Fabric you still need Fabric API.

## Still supported

- Minecraft 1.21.1 on Fabric and NeoForge.
- Minecraft 1.20.1 on Fabric and Forge.

There are no gameplay, config or save changes on 1.20.1 and 1.21.1, so you can update those worlds as usual.

## Download the right file

Each file name says its loader and Minecraft version, for example `spore_and_stem-neoforge-26.3-2.0.2.jar`. Pick
the one that matches your loader and your Minecraft version.
